# 収益化ガイド（自動コンテンツ配信）

毎日 18:41（日本時間）に GitHub Actions（`daily-content`）が次をすべて自動で行います。設定していない投稿先は自動でスキップされるので、できるところから順に始められます。

```
                          ┌─ YouTube ショート（本命・データ動画）────── 広告収益（YPP）
 SNS の対戦報告 ──集計──┤─ TikTok（下書きに送信 → スマホで投稿）──── Creator Rewards など
 （30分ごと自動収集）     ├─ Bluesky / Mastodon / X（画像付き速報）──── 集客
                          ├─ ブログ記事（GitHub Pages）──────────── AdSense・アフィリエイト
                          └─ 週刊レポート（Markdown）────────────── note などの有料記事

 Google トレンド ────┐
 YouTube 急上昇/検索 ─┼─ 伸びている「悩み・関心」を採点 → Claude が台本 → 話題ネタ動画（確認待ち → 公開）
 自分の動画の再生数 ──┘   （伸びたジャンルは自動で優先度アップ）
```

## まず知っておいてほしいこと（収益の現実）

- **YouTube の広告収益は、パートナープログラム（YPP）に入ってから**です。ショートの条件は「登録者 1,000 人 ＋ 直近 90 日でショート再生 1,000 万回」（または長尺の総再生 4,000 時間）。最初の数か月は収益ゼロが普通です。
- **量産型の動画は収益化を止められやすい**: YouTube は 2025〜2026 年に「inauthentic content（オリジナリティの乏しい量産コンテンツ）」の扱いを厳しくし、チャンネル単位で判定しています。このシステムでは次のように対策しています。
  - 本命は **独自に集計したデータ**（他では見られない数字）の動画
  - 動画の形式を曜日で変える（ランキング／急上昇／勝率／相性／上位帯）。言い回しも毎日変える
  - 話題ネタ動画は既定で **非公開アップロード → あなたが確認して公開**。ときどき自分の声やひと言を足すと、さらに安全です
- **データが薄い日は投稿しません**（`monetize.json` の `video.min_samples`）。現在の実データは直近 7 日で数件しかないため、このままだと「投稿せず」になります。データを増やす方法は README の「データ源の設定」を参照してください（`ANTHROPIC_API_KEY` を入れると取りこぼしが大きく減ります）。

## 1. YouTube（最優先）

1. 投稿用のチャンネルを作る（話題ネタ用にもう1つ作るのがおすすめ。ゲームとお金の話が混ざると視聴者がぶれて伸びにくい）
2. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、**YouTube Data API v3** を有効にする
3. 「認証情報」→「OAuth クライアント ID」→ 種類 **デスクトップアプリ** で作成。OAuth 同意画面は「外部」、テストユーザーに自分のアカウントを追加
4. 自分の PC で（このリポジトリを clone して）:
   ```bash
   pip install -r requirements.txt
   python cli.py youtube-auth --client-id <クライアントID> --client-secret <シークレット>
   ```
   ブラウザで投稿先チャンネルのアカウントを選んで許可すると、リフレッシュトークンが表示されます
   （話題ネタ用チャンネルでも同じ手順でもう1つ取得）
5. リポジトリの Settings → Secrets and variables → Actions → **Secrets** に登録

   | 名前 | 値 |
   |---|---|
   | `YT_CLIENT_ID` / `YT_CLIENT_SECRET` | 手順3の値 |
   | `YT_REFRESH_TOKEN` | 手順4の値（データ動画用チャンネル） |
   | `YT_TOPIC_REFRESH_TOKEN` | （任意）話題ネタ用チャンネルの値 |
   | `YT_API_KEY` | 「認証情報」→「API キー」。トレンド分析（伸びている動画の検索）に使う |

6. **公開投稿の審査**: 審査前の API プロジェクトからアップロードした動画は、YouTube 側で自動的に「非公開」に固定されます。Google の「YouTube API Services - Audit and Quota Extension Form」から審査を申請してください（数日〜数週間）。審査が通るまでは、YouTube Studio で手動で公開に切り替えれば OK です。
7. 最初の数本を YouTube Studio で確認して問題なければ、**Variables** に `SVWB_YT_PRIVACY` = `public` を登録すると以後は公開で投稿されます。

> 1 日のクォータ（既定 10,000 ユニット）: アップロード 1 本 1,600、トレンド検索 1 語 100。既定設定（データ動画 1 本＋話題 1 本＋検索 12 語）で約 4,500 ユニットです。

## 2. 読み上げ音声（VOICEVOX）

既定で ON（無料、Actions 上で自動起動）。話者は Variables の `SVWB_VOICEVOX_SPEAKER`（3=ずんだもん、2=四国めたん、8=春日部つむぎ、13=青山龍星 など）。
概要欄に必要なクレジット（例「VOICEVOX:ずんだもん」）は自動で入ります。**キャラクターごとの利用規約**（商用可否・クレジット表記）は各キャラクターの公式ページで確認してください。音声なしにする場合は Variables に `SVWB_TTS` = `off`。

BGM を付けたい場合は `assets/bgm/` に音源を置きます（日替わりで使用）。**YouTube オーディオライブラリ**など、商用利用・収益化 OK の音源だけを使ってください。

## 3. 話題ネタ動画（悩み・コンプレックス・興味関心）

- `topics.json` のジャンル（お金・仕事・恋愛・セルフケア・睡眠・メンタル・雑学・AI 便利ワザ）ごとに、**YouTube で「登録者数の割に再生されている」ショート**と **Google トレンドの急上昇ワード**を集め、悩みワード（「できない」「損」「やめたい」など）と一致するものを高く評価します。
- 毎日のネタ候補は `content/ideas/日付.md` に保存され、Actions の画面（Summary）にも出ます。**台本を作らなくても、ネタ帳として使えます。**
- `ANTHROPIC_API_KEY` を Secrets に入れると、上位のネタから Claude が台本を書いて動画にします（既定 1 本／日、Variables の `SVWB_TOPIC_VIDEOS` で変更）。
- **歯止め**: 外見・体型などのコンプレックスを笑う・あおる表現、医療・投資・法律の断定、根拠のない数字は使わないようプロンプトで指示し、AI にリスク（low/medium/high）と事実確認の要否を自己申告させています。
  - 既定ではすべて **非公開でアップロード**（確認待ち）。Summary に一覧が出るので、YouTube Studio で中身を確認して公開してください
  - Variables に `SVWB_TOPIC_AUTOPUBLISH` = `on` を入れると、**リスク low かつ事実確認不要**のものだけ自動で公開設定にします
- ジャンルの追加・停止は `topics.json` を編集（`enabled: false` で停止）。投稿した動画の再生数を毎日取り直し、伸びたジャンルの重みを自動で上げます（0.6〜1.6 倍）。

## 4. TikTok

TikTok の API は、審査前のアプリだと公開投稿ができません。そこで **「受信箱（下書き）」に送る**方式にしています。スマホの TikTok アプリに通知が来るので、流行りの音源やキャプションを付けて投稿ボタンを押すだけです（TikTok では音源選びが再生数に効くので、ここだけ人がやるのが実は効率的です）。

1. [TikTok for Developers](https://developers.tiktok.com/) でアプリを作り、Content Posting API と `video.upload` スコープを追加
2. 自分のアカウントで認可してリフレッシュトークンを取得（365 日有効）
3. Secrets: `TIKTOK_CLIENT_KEY` / `TIKTOK_CLIENT_SECRET` / `TIKTOK_REFRESH_TOKEN`

## 5. Bluesky / Mastodon / X

| 投稿先 | Secrets | 費用 |
|---|---|---|
| Bluesky | `BSKY_POST_HANDLE` / `BSKY_POST_APP_PASSWORD`（無ければ収集用の `BSKY_HANDLE` / `BSKY_APP_PASSWORD` で投稿） | 無料 |
| Mastodon | `MASTODON_INSTANCE`（例 `mstdn.jp`）/ `MASTODON_TOKEN`（設定 → 開発 → 新規アプリ、`write:statuses` `write:media`） | 無料 |
| X | `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_SECRET`（developer.x.com、App permissions を Read and write に） | Free プランは投稿数に上限あり |

## 6. ブログ記事・広告・アフィリエイト

- 毎日の環境まとめ記事が `https://<ユーザー>.github.io/<リポジトリ>/articles/` に自動で増えていきます（RSS・サイトマップ付き）。
- `monetize.json` を GitHub の画面から編集するだけで反映されます。
  - `adsense_client`: AdSense に合格したら `ca-pub-…` を入力 → 全記事とダッシュボードに広告枠。**AdSense は独自ドメインが事実上必要**です（`ads.txt` をドメインの直下に置く必要があるため）。GitHub Pages に独自ドメインを設定してから申請してください。
  - `affiliate`: Amazon アソシエイト・もしもアフィリエイト・A8.net などのリンク。**「PR」表記を自動で付けます**（2023 年 10 月からのステマ規制への対応）。`amazon_associate: true` で Amazon の定型文も表示。
  - `support_links`: note のメンバーシップや有料記事へのリンク。

## 7. 有料レポート（note など）

毎回 `weekly_report.md`（全デッキの使用率・勝率・信頼区間・相性表・ランク帯別）を作ります。Actions の Artifacts からダウンロードして note に貼り、`<!-- ここから下を有料部分にする -->` の位置に有料ラインを置いてください。
※公開リポジトリの Artifacts は GitHub にログインした人なら誰でも取得できます。厳密に有料にしたい場合はローカルで `python cli.py content` を実行してください。

## 8. 仕組みそのものを売る（任意）

このリポジトリは「SNS 収集 → 集計 → 動画・記事・SNS 自動配信」を無料枠で回す構成なので、ほかのゲームやジャンル向けに作り替えたテンプレートや導入代行を、BOOTH・note・ココナラなどで販売することもできます。その場合は、ゲーム会社の素材を使っていないこと（このシステムは図もすべて自前で描いています）と、各 API の規約を守る運用であることを説明に書いてください。

## 毎日の運用（5 分）

1. Actions → daily-content → 最新の実行の **Summary**（日報）を見る
2. 話題動画が「確認待ち」なら YouTube Studio で中身を見て公開
3. TikTok アプリに届いた下書きに音源を付けて投稿
4. 週 1 回、`content/ideas/` のネタ候補と、YouTube Studio のアナリティクスで伸びた動画の傾向を見て、`topics.json` の `seeds` を足す

## Variables（Settings → Secrets and variables → Actions → Variables）

| 名前 | 既定 | 内容 |
|---|---|---|
| `SVWB_YT_PRIVACY` | `private` | データ動画の公開範囲（`public` / `unlisted` / `private`） |
| `SVWB_TOPIC_AUTOPUBLISH` | `off` | `on` でリスク low の話題動画を自動で公開設定に |
| `SVWB_TOPIC_VIDEOS` | `1` | 1 日に作る話題動画の本数 |
| `SVWB_TTS` | （on） | `off` で読み上げなし |
| `SVWB_VOICEVOX_SPEAKER` | `3` | VOICEVOX の話者 ID |
| `SVWB_CONTENT_LLM` | `off` | `on` でデータ動画の台本も Claude が自然な言い回しに整える（数字は変えない） |

## 手元で試す

```bash
pip install -r requirements.txt
python cli.py demo                                   # 架空データ（確認用）
python cli.py content --out dist/content --scale 0.5 # 動画・記事・SNS 文を作る（投稿はしない）
python cli.py trends                                 # 今日のネタ候補（YT_API_KEY があると精度が上がる）
```
動画の書き出しには `ffmpeg` と日本語フォント（Noto Sans CJK など）が必要です。
