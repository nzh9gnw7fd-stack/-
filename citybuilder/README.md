# はこにわタウン

道路を引いて住宅・商業・工業の区画を塗り、ミニチュアの街を育てる 3D 街づくりゲーム。
ブラウザだけで動き、スマホではホーム画面に追加するとアプリとして起動できます（PWA・オフライン対応）。

## 遊び方

1. **道路を引く**：「道路」を選んでドラッグ。川の上は橋になる（400円）。
2. **区画を塗る**：住宅（緑）・商業（青）・工業（黄）を道路沿いにドラッグで塗る。道路に接していない区画には建物が建たない。
3. **需要を見る**：右上の「住・商・工」バーが上に伸びている種類ほど育ちやすい。住む人は仕事を、お店は客を必要とする。
4. **しあわせ・地価を上げる**：公園（周囲3マス）、川・木の近く、時計塔（周囲6マス、人口300人で解放）で地価が上がり、高い建物が建つ。工場の近く（2〜3マス）は地価としあわせが下がる。

時間は1時間ごとに進み、税収（人口・仕事の数に比例）から維持費（道路・公園・時計塔）を引いた額が資金に加わる。
建物は人口が増えるにつれて最大3段階まで育つ（住宅 Lv2=人口40、Lv3=人口250 など）。夜になると窓に明かりがつく。

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | 右ドラッグ／「見る」ツールでドラッグ | 「見る」ツールで1本指、または2本指 |
| 拡大・縮小 | ホイール／+ − | ピンチ |
| 回転 | Q / E | 左下のボタン |
| 一時停止 | Space | 上の ⏸ |
| ツール切替 | 1〜9 | 下のトレイ |

街はブラウザ（localStorage）に自動保存されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（HTML/CSS/JS 1枚、three.js r128 を cdnjs から読み込み） |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ホーム画面に追加するためのアプリ情報とアイコン |
| `sw.js` | オフラインでも遊べるようにするキャッシュ |

## ローカルで動かす

```bash
cd citybuilder && python3 -m http.server 8000   # http://localhost:8000
```

## 公開

`main` に入ると、既存の `.github/workflows/update.yml` が GitHub Pages の `/town/` にこのフォルダをコピーして公開する
（例：`https://<ユーザー名>.github.io/<リポジトリ名>/town/`）。
